# Master §30 first-candidate acceptance matrix

**Audit date:** 2026-10-09  
**Scope:** The fourteen user-visible steps in `docs/00-master-spec.md` §30 and the cross-cutting dark/light, VoiceOver, degraded-network, and provider-credential conditions. This is a source-and-existing-evidence audit, not a new test run.

## Status meanings

- **Proved in simulator (mock):** an existing simulator run is recorded and the UI assertion covers the stated mock behavior. This is not hosted-provider, production-data, or device proof.
- **Partial:** a related UI path exists or ran, but it does not cover the whole §30 acceptance step.
- **Pending:** no matching end-to-end UI test or no recorded pass was found.

These are the named tests available to assemble a repeatable simulator pass; this document does not claim they were all rerun for this audit. Use the mocks where their test setup requires them, and keep the run serial as required by the progress notes.
